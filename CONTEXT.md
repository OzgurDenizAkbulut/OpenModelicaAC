# OpenModelica

## Language

### OMEdit analysis figures

**Analysis figure**:
An editable scientific visualization of simulation results, displayed in an optional window in OMEdit's Plotting workspace.
_Avoid_: Animation scene

**Figure definition**:
The saved choices of plot types, variable assignments, layout and appearance needed to recreate an analysis figure from its source results.
_Avoid_: Exported image

**Figure panel**:
One 2D or 3D plot within an analysis figure's row-and-column layout.
_Avoid_: Analysis window

**Pinned run**:
A simulation run whose result data is retained for an analysis figure even when a later simulation produces new results.
_Avoid_: Pinned filename

**Result playback**:
Time-controlled inspection of stored simulation results.
_Avoid_: Live simulation
